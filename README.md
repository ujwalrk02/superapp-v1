# kwattel_v2

Mobile wallet UI prototype (AkiPaga) built with plain HTML, CSS and JavaScript. No build step or dependencies.

## Pages

| File          | Description                        |
| ------------- | ---------------------------------- |
| `index.html`  | Landing homepage with app links    |
| `user.html`   | Customer wallet app                |
| `merchant.html`| Merchant app                      |

## Run

Open any file directly in a browser, e.g.:

```
start user.html
```

## Notes

- Demo data is mocked in JS (see `HISTORY`, `CATEGORIES`, `BILLERS` in `user.html`).
- Screens slide in instantly (no transitions).
